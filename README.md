## 🧠 Sobre mim

Sou estudante de **Engenharia de Software** e desenvolvedor **Full Stack em formação**, com experiência prática na criação, manutenção e evolução de sistemas empresariais.

Trabalho com desenvolvimento web, APIs, bancos de dados, integrações entre sistemas, infraestrutura Linux, sistemas legados, ERPs e automações utilizando Inteligência Artificial.

Tenho experiência com ferramentas como **Claude e OpenAI**, aplicadas na análise de código, criação de agentes especializados, engenharia de prompts, documentação técnica, automação de processos e desenvolvimento assistido por IA.

Meu objetivo é transformar problemas reais em soluções inteligentes, escaláveis, seguras e funcionais.
